# NestAI – Move with Confidence

An intelligent multi-agent relocation assistant designed to help families relocate to a new city with confidence. NestAI coordinates specialized sub-agents covering housing, schooling, healthcare, transit, and budgeting to produce a unified quality-of-life assessment called **LifeScore**.

This project is built using the **Google Agent Development Kit (ADK) 2.0** framework and adheres to professional software architecture and security standards.

---

## 🌟 Key Features (Target Design)
*   **Decentralized Specialist Architecture**: Direct division of concerns across five domain-specific specialists under a Coordinator Agent.
*   **Google ADK 2.0 Task Mode**: Strict structured Pydantic I/O schemas for predictable, type-safe multi-agent communications.
*   **Calculated LifeScore**: A 0–100 quality-of-life index evaluating housing, schooling, transit ease, affordability, and family-friendliness.
*   **Grounding-First**: Integration of Puppeteer/Web Crawler MCP servers and Google Maps APIs to prevent text hallucinations.

## 🚀 Setup & Local Running (Phase 1)

### Prerequisites
*   [uv](https://docs.astral.sh/uv/getting-started/installation/) (Python package manager)
*   [Node.js / npm](https://nodejs.org/) (for React frontend)
*   [agents-cli](https://adk.dev/) (`uv tool install google-agents-cli`)

### 1. Copy Environment variables
```bash
cp .env.example .env
# Edit .env and supply your GOOGLE_CLOUD_PROJECT or GEMINI_API_KEY
```

### 2. Install Dependencies
```bash
agents-cli install
```

### 3. Run Backend Server
```bash
uv run python main.py
```
The FastAPI documentation will be available at: [http://localhost:8000/docs](http://localhost:8000/docs)

### 4. Run Frontend Scaffold
```bash
cd frontend
npm install
npm run dev
```
The React frontend will be available at: [http://localhost:5173/](http://localhost:5173/)
